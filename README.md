# صفحهٔ اول روزنامه‌های جهان — می‌نی‌اپ تلگرام

می‌نی‌اپی که هر روز تصویر صفحهٔ اول روزنامه‌های مهم جهان را نشان می‌دهد؛ با لمس هر روزنامه، تیترهای صفحهٔ اول آن به فارسی می‌آید و هر تیتر به مطلب اصلی در سایت همان روزنامه لینک شده است.

## ساختار

- `index.html` — کل برنامه (صفحهٔ اصلی و صفحهٔ هر روزنامه، راست‌به‌چپ، هماهنگ با رنگ‌های تلگرام)
- `scripts/papers.json` — فهرست کشورها و روزنامه‌ها
- `scripts/fetch_covers.py` — دریافت تصاویر امروز از frontpages.com ← `covers/<تاریخ>/`
- `headlines/<تاریخ>.json` — تیترهای هر روزنامه: `[تیتر اصلی, ترجمهٔ فارسی, لینک اختیاری]`
- `scripts/build_data.py` — ساختن `data/<تاریخ>.json`، `data/latest.json` و فهرست بایگانی `data/index.json`

## به‌روزرسانی روزانه

```bash
python3 scripts/fetch_covers.py 2026-10-22
# نوشتن headlines/2026-10-22.json
python3 scripts/build_data.py 2026-10-22
git add -A && git commit -m "2026-10-22" && git push
```

اگر برای تیتری لینک مستقیم داده نشود، لینک به نخستین نتیجهٔ همان تیتر در سایت خود روزنامه می‌رود.
